## Алгоритм (кратко)
1. **Пространство:** модель = пара деревьев `(f1, f2)`; глубина ≤ 4, ≤ 13 вершин на уравнение; допустимы только деревья без деления на 0/inf/nan на данных (равномерное априорное на допустимых).
2. **Оценка модели:** подгонка констант интегральным согласованием → `acc` (1−R² по приращениям), `C` (число вершин + 0.5 на параметр), `S = ln(1 + Δ/acc)` (рост ошибки на чистых данных после переподгонки на 8 наборах с интервенциями).
3. **Прунинг** трёх лучших моделей каждого поколения: удаляется вершина (→0 или → ребёнок), если сложность падает и парный t-критерий не показывает значимого ухудшения (t < 2, рост ошибки ≤ 10 %).
4. **Следующее поколение:** элита (6) + потомки: турнир → кроссовер/мутация; 15 % потомков – кроссовер запрунённой лучшей модели со *случайно сгенерированной новой*.
5. **Архив:** каждая новая структура сохраняется; итоговый граф – лучший по `J` среди классов эквивалентности (раскрытые формулы). Проверка: подгонка по траектории ОДУ, фазовые портреты, интервенция `do(u=1)`.

## Что сознательно упрощено / ограничения
* 21 точка и два периода колебаний: слабые различия в RSS (595 против 450) статистически неразличимы; поэтому выбор – по `J`, а не по RSS.
* Интегральное согласование на годовой сетке с PCHIP-интерполяцией даёт смещённые константы (α≈0.61 против 0.48 по траектории); структура определяется верно, константы уточняются по траектории.
* Устойчивость считается на 8 фиксированных возмущённых наборах (4 типа × 2 seed) – числа зависят от этих розыгрышей.
* Таблица интервенций (W1/σ) для найденной модели считается на интегральном согласовании, поэтому реакция на `zero_lynx` и `shuffle` слабее, чем в ЛР № 2 (подгонка траектории + начальные условия).
* Параметры весов `J` (0.03 на вершину и т.д.) подобраны так, чтобы эталон был оптимальным в широкой области (рис. 07); это не «слепой» выбор.
