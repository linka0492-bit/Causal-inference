# ЛР № 4. Прогноз структуры причинной модели линейной регрессией
Описание вычислительного эксперимента

## 1. Постановка

В ЛР № 1 граф строился, в ЛР № 2 в данные вносились интервенции и граф менялся по критерию, в ЛР № 3 граф порождался генетическим алгоритмом (обратная задача выбора модели). В ЛР № 4 решается **прямая задача**: по выборке прогнозируется структура модели. Метод по номеру задачи — **линейные регрессионные модели**.

Дано: коллекция пар (выборка, целевая модель). Нужно: обучить прогнозную модель на всей коллекции, спрогнозировать модель по одной или нескольким выборкам и показать процедуру последовательностью графов.

## 2. Коллекция

* 11 систем, по 30 экземпляров каждой (330 выборок): Лотка–Вольтерра; её логистический вариант (лишний член x²); три варианта с переменной z из ЛР № 2 (z внутри скобок, множитель, аддитивный источник); Ван-дер-Поль; «взаимная любовь» dx = y, dy = −x; затухающий осциллятор; остывание; Лоренц; Рёсслер. Модели с тремя переменными и драйвером z — «модели с большим числом переменных».
* Экземпляры одной системы отличаются параметрами (±25 %), начальными условиями, числом точек (21 / 41 / 81 для Лотки–Вольтерры) и шумом (до 8 %, для Лоренца 2 %, Рёсслера 3 %).
* Реальная выборка Hudson Bay (21 точка, 1900–1920) в обучение не входит; целевая модель — Лотка–Вольтерра с параметрами ЛР № 1.
* Целевая модель (ground truth) — бинарная матрица Z (уравнения × мономы степени ≤ 3). Она строится из тех же слагаемых, из которых генерируются данные.
* Интервенции в данные — как в ЛР № 1–3: шум 0.3σ, условный шум, малая выборка (12 из 21), смещение +0.25σ; дополнительно зануление, перемешивание 30 %, добавление точек. Для оценки устойчивости — 4 вида × 2 розыгрыша, как в ЛР № 3. Копии с интервенциями (2 на выборку) добавлены в обучение.
* Разбиение внутри каждой системы: 60 % обучение, 20 % валидация (настройка гиперпараметров по J), 20 % тест.

## 3. Метод

**Модель.** dx_i/dt = Σ_j w_ij θ_j(x), θ_j — мономы. Структура — матрица Z; граф суперпозиции строится по Z. Параметры подбираются интегральным согласованием по PCHIP-интерполяции (как в ЛР № 3) с гребневой регуляризацией; после выбора структуры параметры уточняются по траектории ОДУ.

**Прогнозная модель** fai: (выборка, граф z_t) → Γ. Γ[i, j] = clip(β · φ_ij), гребневая линейная регрессия по метке «ребро есть в ground truth». 14 базовых признаков ребра, веса отдельно для рёбер, которые сейчас есть и которых нет (28 весов). Признаки не зависят от названий переменных:
рост ошибки при переключении ребра; парный t-критерий по квадратам невязок (критерий удаления из ЛР № 3, идущий от ЛР № 2); вклад монома и t-статистика его коэффициента; устойчивость коэффициента по мини-батчам (ЛР № 1–2); вклад в плотной модели; размер уравнения и качество подгонки; структура монома (степень, число переменных, «своя» переменная, драйвер, константа).

**Прогноз.** Старт — полный граф. На каждом шаге включаются рёбра с Γ > τ, за шаг меняется не более k самых уверенных рёбер, в уравнении остаётся хотя бы один член. Параметры пересчитываются с наследованием: у оставшихся рёбер значения сохраняются как априорное среднее (−ln p(w) = (w − μ)ᵀA⁻¹(w − μ)), у вылетевших исчезают, у новых начинаются с нуля. В конце — прунинг по критерию из ЛР № 3 (рост ошибки не больше 10 %, парный t < 2).

**Обучение.** Только на совпадении графа с эталоном; ошибка по данным в обучение Γ не входит, но входит в признаки через критерий удаления. Состояния z_t получаются прямым процессом (к эталону добавляются 0–8 ложных рёбер, иногда теряется истинное), затем один раунд DAgger: модель дообучается на графах, которые посещает сама.

**Целевая функция** J = ln(acc) + 0.03·C + S настраивает гиперпараметры (ridge, τ, k, прунинг). acc — доля неверных рёбер (FP + FN)/|эталон| + 0.02; C — сложность спрогнозированных моделей; S = ln(1 + Δ/acc), Δ — рост ошибки графа на 8 испорченных копиях выборки.

**Базовые методы** (та же библиотека): плотная регрессия + порог по вкладу; STLSQ (SINDy); критерий удаления ЛР № 3 без обучения. Пороги подобраны на обучающей части.

## 5. Ограничения

* Метод хорошо работает на системах, похожих на встречавшиеся в обучении; на новых семействах в среднем не лучше критерия ЛР № 3 без обучения (0.40 против 0.41), а на остывании хуже.
* Из ЛР № 1 в отчётах были только Лотка–Вольтерра и Ван-дер-Поль; остальные системы — стандартные. Остальные уравнения ЛР № 1 добавляются через `register_system()`.
* Для малых λ и η (ЛР № 2) эффект z почти неразличим в данных, поэтому структура с такими членами восстанавливается плохо любым методом (в коллекции взяты диапазоны λ ∈ [0.04, 0.12], η, θ ∈ [0.3, 1]; константная z исключена — она неотличима от свободного члена, как отмечено в ЛР № 2).
* Библиотека — мономы степени ≤ 3; уравнения с делением (как у конкурентов в ЛР № 3) в неё не входят.
* Один запуск: одно разбиение и одно начальное число; доверительных интервалов на метриках нет (на тесте 66 выборок). Результаты зависят от выбранных весов J и от состава коллекции.
* Интегральное согласование на разреженных и зашумлённых рядах смещает коэффициенты (в ЛР № 3 α ≈ 0.61 вместо 0.48); для окончательных значений используется подгонка по траектории (для хаотических систем она не делалась).
* Не сделаны: структурная интервенция «лишняя переменная», прогноз структуры и параметров одним совместным процессом без переподгонки, диффузионный/нейросетевой вариант из лекций (он относится к другим номерам задач).

## 6. Воспроизведение

`python run_lab4.py --out results --n 30 --seed 0` (≈ 8 минут, один процессор). Ноутбук `lab4_linear_forecast.ipynb` читает готовые результаты из `results/` и делает прогнозы на новых данных за секунды.
