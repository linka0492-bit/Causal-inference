# ЛР № 4. Прогноз структуры причинной модели линейной регрессией

Прямая задача: по выборке спрогнозировать модель. Метод из списка задач — **линейные регрессионные модели**.

## Как это работает (коротко)

1. **Модель** линейна по коэффициентам: dx_i/dt = Σ_j w_ij·θ_j(x), θ_j — мономы. **Структура** — бинарная матрица Z (уравнения × мономы), то есть матрица смежности двудольного графа «мономы → уравнения».
2. **Прогнозная модель** fai: (выборка, граф z_t) → Γ, где Γ[i, j] — вероятность ребра. Γ — линейная регрессия ребра на 14 признаков, отдельные веса для «ребро есть» и «ребра нет». Признаки не зависят от названий переменных, поэтому одна модель работает для всей коллекции.
3. **Прогноз** — последовательность графов от полного к результату. На каждом шаге включаются рёбра с Γ > τ, меняется не больше k самых уверенных. Параметры наследуются: у оставшихся рёбер значения сохраняются (априорное среднее в гребневой подгонке), у вылетевших исчезают.
4. **Критерий удаления/сохранения ребра** — правило из ЛР № 3 (оно идёт от ЛР № 2: «если удаление ничего не меняет — убираем»): рост ошибки ≤ 10 % и парный t-критерий не значим. Используется и как признак, и как финальный прунинг.
5. **Обучение** — на эталонном графе, а не на ошибке по данным. Состояния z_t получаются прямым процессом (к эталону добавляются ложные рёбра), плюс дообучение на графах, которые модель посещает сама (DAgger), плюс копии выборок с интервенциями в данные.
6. **Целевая функция J** (по образцу ЛР № 3) настраивает гиперпараметры (ridge, τ, k, прунинг): ln(acc) — ошибка восстановления графа, 0.03·C — сложность спрогнозированных моделей, S = ln(1 + Δ/acc) — рост ошибки при 8 испорченных копиях выборки.

## Как подключить прежний код

* **Данные ЛР № 1–3.** Любая выборка — это `Sample(system, family, t, X, names, n_eq, Z, W)`. Достаточно создать его из своих массивов (как `hudson_bay()` в `systems.py`).
* **Свои уравнения.** `register_system(name, family, names, n_eq, fn)`, где `fn(rng)` возвращает `dict(terms=[{(показатели степеней): коэффициент}, ...], x0=..., t=..., driver=...)`. Эталонный граф строится сам из `terms`.
* **Своя интервенция.** функция `(Sample, rng) -> Sample` в `INTERVENTIONS`.
* **Свой критерий удаления ребра.** метод `Equation.removable` в `library.py` — единственное место, где он используется.
* **Свой метод прогноза графа.** любой объект с методом `predict(prep) -> Z (bool, n_eq × K)` работает с `evaluate()` из `objective.py`.

Код не содержит имён авторов и не зависит от среды запуска.

## Ограничения

* Из ЛР № 1 в отчётах были только Лотка–Вольтерра и Ван-дер-Поль; остальные системы (осцилляторы, остывание, Лоренц, Рёсслер) — стандартные. Остальные уравнения вашей ЛР № 1 добавляются через `register_system()`.
* Для малых λ и η (ЛР № 2) эффект z почти не виден в данных, структуру с такими членами по данным восстановить нельзя; в коллекции они взяты в диапазонах, где различимость ещё возможна.
* Библиотека — мономы степени ≤ 3; уравнения с делением (как в ЛР № 3 у конкурентов) в неё не входят.
