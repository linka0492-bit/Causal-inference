# Модель Вольтерра-Лотки (Лотки-Вольтерра)

Система дифференциальных уравнений, описывающая динамику взаимодействия двух видов в экосистеме — классически **«хищник-жертва»** (predator-prey).

## Уравнения

```
dx/dt = αx - βxy
dy/dt = δxy - γy
```

Где:

| Символ | Значение |
|--------|----------|
| `x` | численность жертв (например, зайцы) |
| `y` | численность хищников (например, рыси) |
| `α` | коэффициент естественного прироста жертв (без хищников) |
| `β` | коэффициент гибели жертв от хищников |
| `δ` | коэффициент роста хищников за счёт поедания жертв |
| `γ` | коэффициент естественной убыли хищников (без пищи) |

## Логика модели

- **Жертвы** размножаются экспоненциально (`αx`), но гибнут пропорционально числу встреч с хищниками (`βxy`)
- **Хищники** размножаются за счёт поедания жертв (`δxy`), но вымирают без пищи экспоненциально (`γy`)

## Поведение системы

Классический результат — **циклические колебания**:

1. Много жертв → хищники размножаются
2. Много хищников → жертвы истребляются
3. Мало жертв → хищники начинают вымирать от голода
4. Мало хищников → жертвы снова размножаются
5. Цикл повторяется

Популяции колеблются с фазовым сдвигом: пик численности хищников следует за пиком численности жертв с задержкой.

## Важные свойства

- Система имеет **точку равновесия** (стационарное состояние): `x* = γ/δ`, `y* = α/β`
- Траектории на фазовой плоскости `(x, y)` — замкнутые кривые (эллипсоподобные); система **консервативна** — не затухает и не расходится сама по себе
- Модель сильно упрощена: не учитывает ограниченность ресурсов (ёмкость среды), возрастную структуру, случайные факторы и т.д.

## Где применяется

- 🌿 Экология (динамика популяций)
- 💹 Экономика (модели конкуренции, например «фирмы-потребители»)
- ⚗️ Химическая кинетика (автокаталитические реакции)
- 🦠 Эпидемиология (в модифицированном виде)
