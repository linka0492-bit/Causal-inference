Модель Вольтерра-Лотки (Лотки-Вольтерра)
Это система дифференциальных уравнений, описывающая динамику взаимодействия двух видов в экосистеме — классически «хищник-жертва» (predator-prey).
Уравнения
$$\frac{dx}{dt} = \alpha x - \beta xy$$
$$\frac{dy}{dt} = \delta xy - \gamma y$$
где:
$x$ — численность жертв (например, зайцы)
$y$ — численность хищников (например, рыси)
$\alpha$ — коэффициент естественного прироста жертв (без хищников)
$\beta$ — коэффициент гибели жертв от хищников
$\delta$ — коэффициент роста хищников за счёт поедания жертв
$\gamma$ — коэффициент естественной убыли хищников (без пищи)
Логика модели
Жертвы размножаются экспоненциально ($\alpha x$), но гибнут пропорционально числу встреч с хищниками ($\beta xy$)
Хищники размножаются за счёт поедания жертв ($\delta xy$), но вымирают без пищи экспоненциально ($\gamma y$)
Поведение системы
Классический результат — циклические колебания:
Много жертв → хищники размножаются
Много хищников → жертвы истребляются
Мало жертв → хищники начинают вымирать от голода
Мало хищников → жертвы снова размножаются
Цикл повторяется
Популяции колеблются с фазовым сдвигом: пик численности хищников следует за пиком численности жертв с задержкой.
Важные свойства
Система имеет точку равновесия (стационарное состояние): $x^* = \gamma/\delta$, $y^* = \alpha/\beta$
Траектории на фазовой плоскости $(x, y)$ — замкнутые кривые (эллипсоподобные), система консервативна — не затухает и не расходится сама по себе
Модель сильно упрощена: не учитывает ограниченность ресурсов (ёмкость среды), возрастную структуру, случайные факторы и т.д.
Где применяется
Экология (динамика популяций)
Экономика (модели конкуренции, например «фирмы-потребители»)
Химическая кинетика (автокаталитические реакции)
Эпидемиология (в модифицированном виде)
